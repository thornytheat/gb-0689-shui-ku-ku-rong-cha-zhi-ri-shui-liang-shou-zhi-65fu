# 水位与水量定义

id、station为字符串。time含时区，统一UTC，日账在+08:00午夜拆分。level单位m；inflow/outflow单位m3/s或L/s，归一m³/s；空值不等于零。负流量与曲线外水位隔离。
水位与流量是两路独立序列：单元格为空表示该路未回传，测次可只带水位或只带流量，但入流与出流缺一不成流量、两者皆空不成测次，均整行隔离；显式哨兵（NULL、未知等）视为已报但无效，同样整行隔离。
curve为[[水位,库容],...]，水位及库容必须严格递增，库容非负，单位m与m³。只对范围内水位分段线性插值，端点允许。
同站同刻按version最高记录采信，同版不同值全部隔离。同版互补的水位报与流量报合并为一条测次，被并入的行保留为重复证据。重复旧版有独立证据。输入=采信+隔离；原始行号保留。
流量序列相邻观测间以梯形积分计算流量体积，水位序列相邻观测间线性变化并按曲线换算库容，两路分别连成各自的段，超过max_gap_hours则不插补。日界处先线性插出流量与水位，再分别积分及换算。
日账分轨入账：in_m3/out_m3是流量序列覆盖时段的体积，storage_change是水位序列覆盖时段的库容变化，各自带flow_windows/level_windows（+08:00）与flow_hours/level_hours作为交班依据时段；residual=库容变化-入库+出库只按两轨共同覆盖的窗口计算，共同覆盖时长为compare_hours，无共同窗口则为空。覆盖时长按整秒累加后一次折算，满覆盖24h才判完整。
日状态：完整=两路均覆盖24h；部分=两路均有覆盖但不足24h，可交班、待补测；缺测=一路完全无覆盖。完整日收支差绝对值超过tolerance_m3需复核。缺测优先于超差。无蒸发降雨模型，差额不自动认作漏损。
数值为Decimal字符串，日切与整段积分容许1e-9m³以内十进制除法尾数。规则参数和输入摘要参与幂等ID；批次原子保存，复核版本冲突返回409。
后补数据重跑同一天是整日重算而非增量累加：每个时段在同一批次内只计一次，相同输入复用同一批次，新数据产生新批次，旧批次及其依据时段保留不丢。

原始到达序小于此前最大事件时刻的测次标记arrival=迟到，仍保留并按事件时间排序积分，迟到不会推进水位回退。
